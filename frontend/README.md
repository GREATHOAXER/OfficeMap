# OfficeMap 화면 (Next.js)

```bash
npm install
cp -n .env.example .env.local   # 처음 한 번만. Windows: if not exist .env.local copy .env.example .env.local
npm run dev                  # http://localhost:3000
```

API 서버(`server/`, uvicorn)가 `http://localhost:8000`에서 떠 있어야 로그인이 됩니다.
브라우저는 `/api/...`로만 요청하고, Next.js가 `API_URL`로 넘겨줍니다(`next.config.ts`).
개발 서버를 localhost가 아닌 주소(ngrok 등)로 열려면 그 호스트 이름이 `allowedDevOrigins`에 있어야 합니다(없으면 개발용 연결이
막혀 버튼이 동작하지 않음). `next.config.ts`가 `.env.local`의 `DEV_ORIGINS`와, 개발 서버를 켤 때 돌고 있는 ngrok의 주소
(ngrok 관리 화면 API `127.0.0.1:4040`)를 넣습니다. 그래도 막히면 개발 서버에서만 몇 초 뒤 화면 위에 고치는 법을 띄웁니다
(`components/DevHostHint.tsx`). 로그인·관리자 로그인·비밀번호 변경 폼은
`method="post"`라서 스크립트가 뜨기 전에 눌려도 비밀번호가 주소에 남지 않습니다. 로그인 응답이 성공이면 한 번 더 확인해서
(`confirmLogin`: 응답이 이 서버의 JSON인지, 다음 요청에 로그인 쿠키가 실리는지) 아니면 다음 화면으로 넘기지 않고 이유를 보여 줍니다.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 (코드 바꾸면 바로 반영) |
| `npm run build` / `npm start` | 운영용 빌드와 실행 |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript 검사 |

`npm run dev`·`npm run build`는 먼저 `scripts/copy-pdfjs.mjs`로 pdf.js 일꾼·글꼴·문자표를 `public/pdfjs/`에 복사합니다
(git에는 넣지 않음). 도면 파일(PDF) 가져오기가 브라우저에서 이 파일들을 받습니다. pdf.js는 사내 PC의 조금 오래된
브라우저에서도 돌도록 호환(legacy) 빌드를 씁니다.

`npm audit`이 깨끗하도록 `package.json`의 `overrides`로 exceljs가 쓰는 `uuid`를 11.1.1로 올려 둡니다
(exceljs 4.4.0은 uuid 8을 요구하지만 쓰는 함수 `v4`는 그대로 있습니다). 의존성을 바꾼 뒤에는 `npm audit`으로 확인하세요.

## 화면 속도

휴대폰·느린 망(ngrok 터널)에서도 빨리 뜨도록 한 것들입니다. 같은 조건(지연 200ms, 5Mbps, CPU 4배 느림, 첫 방문)에서
첫 화면 로드가 8.9초 → 1.7초, 요청 235개 → 31개, 받는 양 2MB → 237KB가 됐습니다.

- **글꼴**: 본문(한글)은 기기 글꼴(맑은 고딕·Apple SD 고딕 Neo·Noto Sans KR 등, `globals.css`의 `--font-body`)을 씁니다.
  한글 웹 글꼴은 글자 묶음 파일이 200개 넘게(첫 화면 1.7MB) 받아져서 뺐습니다. 숫자용 고정폭 글꼴(IBM Plex Mono, 20KB)만
  `next/font`로 이 서버가 제공합니다.
- **CSS**: `next.config.ts`의 `experimental.cssChunking: "graph"`로 화면마다 쓰는 CSS만 받습니다(직원 화면이 관리자 화면 CSS를
  받지 않음, 68KB → 11~22KB).
- **미리 받기**: 층 탭과 도면의 회의실 상자는 `prefetch={false}`. 서버가 그때의 자리·재실을 그리는 화면이라 미리 받아 둘 것이
  없고 요청만 늘었습니다. 왼쪽 메뉴는 미리 받습니다(로딩 자리가 바로 뜨도록).
- **로딩 자리**: 메뉴로 옮겨 갈 때 바로 보이는 `loading.tsx`. 주소의 `?floor=`·`?date=`만 바꾸는 화면(자리 현황·회의실·
  도면 편집·좌석 배치)에는 두지 않습니다(층·날짜를 바꿀 때마다 화면 전체가 깜빡임). 조직도는 부서를 고를 때 주소만 바꿉니다
  (`history.replaceState`, 전에는 부서마다 서버가 조직도 전체를 다시 그림).
- **도면 다시 그리기**: 좌석(`SeatButton`)은 `memo`라 배율을 바꾸거나 누군가의 재실이 바뀌면 바뀐 자리만 다시 그립니다
  (핀치는 초당 수십 번 배율이 바뀜).
- 개발 서버(`npm run dev`)는 화면을 처음 열 때마다 컴파일하고 JS도 몇 배 커서, 휴대폰·ngrok으로 볼 때는 빌드해서 띄우세요.
- 다시 재기: 측정 스크립트(서버 렌더 시간, 페이지별 글꼴·CSS·JS, 데스크톱·휴대폰 CPU, 느린 망 첫 방문·메뉴 이동, 미리 받기)를
  같은 조건으로 돌려 비교합니다.

## 왼쪽 메뉴 접기

- 햄버거 버튼으로 접고 펴면 본문 폭이 그만큼 늘고 줄며, 도면도 같이 커지고 작아집니다.
- 고른 상태는 `officemap_sidebar` 쿠키에 남아 새로고침해도 유지됩니다.
- 한 번도 고르지 않았으면 펼칩니다.
- 휴대폰(720px 이하)에서는 왼쪽 메뉴가 숨고, 위쪽 막대의 햄버거로 서랍처럼 엽니다. 바깥을 누르거나 Esc,
  메뉴를 고르면 닫힙니다 (화면 폭을 늘 차지하던 아이콘 줄이 없어 본문이 넓어집니다).
- 관리자 화면의 작은 글자(10~14px)는 휴대폰(720px 이하)에서 한 단계(약 2px, 15px까지) 키웁니다. 관리자 CSS 모듈마다
  끝에 있는 `@media (max-width: 720px)` 블록이고, 칸이 좁으면 줄을 바꿔 잘리지 않게 합니다 (아이폰 13·mini 폭에서 점검).
- 아직 화면이 없는 메뉴(AI 도우미, 좌석 배치 편집 등)에는 "준비 중"이 보입니다.
- 아래 사용자 칸의 계정 메뉴는 body에 띄워서, 메뉴를 접었을 때도 아바타 오른쪽에 가려지지 않고 뜹니다.

## 도면 확대·축소

- 버튼(－ / ＋ / 맞춤) 외에 트랙패드 두 손가락 벌리기·오므리기로 50%~300% 사이를 확대·축소합니다. 층을 바꾸면(뒤로 가기 포함) 100%로 돌아갑니다.
  손가락이 있는 곳을 기준으로 커지고, 두 손가락으로 밀면 그대로 스크롤됩니다.
- Chrome·Edge·Firefox는 핀치가 `ctrlKey`가 붙은 `wheel` 이벤트로 오고(Ctrl+마우스 휠도 같음),
  Safari는 `gesturechange`의 `scale`로 옵니다. 도면 위에서만 막아서 브라우저 화면 전체는 커지지 않습니다.
- 휴대폰·태블릿은 두 손가락 터치로 도면만 확대·축소합니다(`touchstart`/`touchmove`, 손가락 사이가 벌어진 비율만큼).
  손가락 가운데가 기준이고, 두 손가락을 같이 움직이면 도면을 옮기며, 한 손가락은 그대로 스크롤입니다. 도면 영역은
  `touch-action: pan-x pan-y`라 그 위에서는 브라우저 화면 확대가 일어나지 않습니다(도면 밖은 그대로 확대 가능).
  iPhone Safari가 같이 보내는 `gesture*` 이벤트는 터치로 처리 중이면 무시해서 두 번 커지지 않고, 핀치를 마치고
  손가락을 뗄 때 그 아래 자리가 눌리지 않습니다.
- 확대해서 도면이 영역보다 커지면 마우스로 잡고 끌어서 옮깁니다(손 모양 커서). 5px 넘게 움직여야 끌기로 봐서,
  그냥 누르면 자리 고르기 그대로입니다.
- 자리 이름·재실 표시·의자는 도면 폭 기준(cqw) 크기라 확대하면 같이 커집니다.
- **좌석 이름 크기** (`lib/seatLabel.ts`, 직원 화면·좌석 배치 편집·도면 편집이 같이 씀): 층의 보통 책상에 "● 가나다"
  (재실 표시 + 세 글자 이름)가 다 들어가는 크기를 층 기본 글자 크기로 정하고, 이름이 더 긴 자리만 줄입니다.
  기본 크기도 자리마다 쓰는 여백(0.15em)을 같이 넣어 셈해서, 세 글자 이름이 100%에서 실제로 8.5px 이상입니다.
  세로로 긴(돌린) 책상은 이름을 세로로 쓰고, 세로 글자가 한 글자에 차지하는 높이(약 1.5em)로 재서 잘리지 않게 합니다.
  세로 이름 칸 끝에는 0.8em 여유를 둡니다(글꼴에 따라 세로 글자가 제자리보다 아래에 그려져 마지막 글자가 잘렸음).
  직원 화면에서는 자리마다 그 자리 이름 글자가 6.5px보다 작으면(돌린 책상·아주 긴 이름) 그 자리만 이름을 숨기고 재실 표시만 둡니다
  (`FloorPlan`의 `markTinySeats`, 층 전체를 숨기는 "전체 보기"와 같은 기준).
  의자도 책상 깊이에 맞춥니다.
- **사람이 많은 층**: 책상 크기는 실제 미터라 사람이 많아 책상이 작은 층(8F)은 좌석도 작게 그려집니다. 대신 100%에서 이름이
  8.5px보다 작아지지 않도록 도면을 화면보다 넓게 그리고(끌어서 옮겨 봄), 이때 "맞춤" 대신 "100%"와 "전체 보기" 단추가 보입니다.
  "전체 보기"는 층 전체가 한 화면에 들어오는 배율이고, 이름이 6.5px보다 작아지면 이름은 숨기고 재실 표시만 남깁니다
  (자리에 마우스를 올리거나 누르면 정보 카드). 보통 층은 1440px 화면에서 지금처럼 카드 폭에 맞습니다.

## 자리 정보 카드와 검색

- 자리에 마우스를 0.7초 올려 두면 그 사람의 사진·이름·팀·한 줄 소개·재실 상태·업무 키워드·내선이 카드로 뜹니다
  (키보드로 자리에 가도 같음). 자리를 누르면 오른쪽 패널에 "하는 일"까지 보입니다. 카드는 도면 영역 밖으로 나와도
  잘리지 않게 화면 위 층에 띄우고, 자리 위가 좁으면 아래로·옆으로 옮깁니다. 긴 상태 메시지는 줄을 바꾸고, 키워드가
  4개보다 많으면 "+N".
- 오른쪽 패널이 도면 아래로 내려가는 좁은 화면에서는 자리를 누르면 같은 카드가 자리 옆에 고정돼 뜹니다.
  Esc, 닫기 버튼, 바깥을 누르면 닫힙니다.
- 머리글 검색창에 이름·팀·사번, 또는 "내 정보"의 하는 일·업무 키워드·부르는 이름을 치면 아래에 결과 목록이 뜹니다
  (하는 일로 찾은 사람은 걸린 부분이 파랗게 보입니다. 예: "법인카드"). 고르면 그 사람 층으로 가서 자리를 가운데로
  가져오고 골라 둡니다. 다른 층이면 주소가 `/?floor=층ID&seat=자리ID`로 바뀝니다. 주소의 `seat=`는 지금 고른 자리를 따라가고
  (Esc로 해제하면 빠짐) 새로고침하면 그 자리가 다시 골라집니다. 검색어는 50자까지. 자리가 없는 사람을 고르면 연락처 카드가 뜹니다.
- 재실 상태는 자리에 있음 4가지(재실 · 방해 금지 · 회의 중 · 잠시 자리 비움)와 자리에 없음 6가지(외근 · 출장 · 재택 ·
  교육 · 휴가 · 부재)입니다 (`lib/presence.ts`, 서버 `presence.py`, DB `db/schema/14_presence_statuses.sql`이 같아야 함).
  표시는 색과 모양을 둘 다 다르게 했습니다: 재실 초록 원, 방해 금지 빨간 원에 흰 줄, 회의 중 보라 네모,
  잠시 자리 비움 주황 반쯤 찬 원, 외근 갈색 마름모, 출장 파란 세모, 재택 청록 집, 교육 분홍 빈 네모, 휴가 하늘색 고리,
  부재 회색 점선 원, 상태 없음 빈 회색 원 (`globals.css` `.mk`, 범례·거르기·층 요약 숫자에도 "상태 없음"이 있음).
  층 요약·팀 현황 숫자는 자리에 없는 상태를 그 상태인 사람이 있을 때만 보여 줍니다.
- 휴가·출장처럼 자리에 없는 상태는 자리 카드·마우스를 올린 카드·팀 현황에 기간이 같이 보입니다 ("휴가 · 10/31(토)까지",
  오늘 풀리면 "18:00까지"). 자리에 있는 상태가 오늘 풀리는 것은 따로 쓰지 않습니다 (`presencePeriod`).
- 카드·오른쪽 패널에 언제 바꾼 상태인지("12분 전 변경")와 해제 시각이 보여서 오래된 상태를 알아볼 수 있습니다.
- 내 자리는 "나" 표시와 굵은 테두리. 내 자리를 누르면 "내 재실 상태 바꾸기" 바로가기가 있습니다.
- 휴대폰에서 자리를 누르면 정보가 화면 아래 시트로 뜹니다 (도면 가장자리에서 잘리지 않게). 스크롤해서 도면 아래의
  자리 카드(같은 사람, 더 자세히)가 화면에 들어오면 시트는 숨겨 둘이 겹치지 않고, 도면으로 다시 올라가면 돌아옵니다.
- 상태 필터를 걸면 도면 위에 "필터 적용 중 · 모두 보기"가 뜹니다 (다른 층으로 가도 유지되므로).
- 도면의 회의실을 누르면 회의실 화면이 그 층으로 열립니다. 자리가 아직 없는 사람은 우리 팀 층이 열리고 안내가 뜹니다.
- 키보드: "도면 건너뛰기" 링크, 도면의 자리들은 Tab 한 번(고른 자리 또는 첫 자리)으로 들어가 방향키로 가까운 자리로 옮깁니다.
  고른 자리는 Esc로 해제.
- 팀 구역: 도면에는 구역 이름을 쓰지 않고 색으로만 구분합니다 (좁은 조각·겹친 조각에서 이름표가 가려졌음). 도면 위
  팀 칩이 범례로, 도면의 구역과 같은 채움·테두리(공용 구역은 점선)에 작은 책상의 위쪽 띠도 팀 색입니다. 칩에 마우스를 올리면
  그 구역을 미리 진하게, 누르면 고정합니다(다시 누르면 해제). 한 팀 구역이 한 층에 둘 이상이면 칩에 구역 기호(A·B)가 붙습니다.
  도면의 빈 구역 자리에 마우스를 올려도 이름이 뜹니다.
  내보낸 그림(PNG·PDF)과 이사 도우미 도면은 도면 아래에 같은 범례를 그립니다.
- 층 탭: 팀 구역이 없는 층은 부제를 비우고(도면이 없으면 "도면 없음"), 탭이 넘치면 ‹ › 단추로 넘기며 고른 층이 보이게 합니다.
  누르면 그 층을 받아 오는 동안 탭 아래에 움직이는 줄이 뜹니다. 사업장을 처음 열면 도면이 있는 층부터 엽니다.
- 열어 둔 채로 시간이 지나도 맞게: 회의실 상자("사용 중 ~14:00", "비어 있음 · 15:00까지")와 재실 상태 자동 해제는
  그 상태가 바뀌는 시각과 자정에 한 번 서버 데이터를 다시 읽습니다(`lib/useRefreshAt.ts`, 1분마다 묻지 않음).
- 이름표를 비운 공간(탕비실·화장실 등)은 종류 이름을 보여 줍니다. 회의실·공간 이름은 칸 안에 들어가게 줄입니다.
- 층 요약의 빈 자리 수에서 사용 중지 자리는 뺍니다.

## 회의실 확인·예약

- 사업장끼리는 섞지 않습니다. 사업장이 둘 이상이면 날짜 아래 왼쪽에 사업장 버튼(서울 본사 · 분당 센터 …)이 서로 떨어져 있고,
  세로줄 오른쪽의 층 버튼은 고른 사업장의 층만 보여 줍니다. 자리 현황 도면의 회의실(다른 사업장 층 포함)을 누르면
  `/rooms?floor=층ID`로 그 층의 사업장이 열립니다(사업장을 주지 않으면 서버가 층의 사업장을 찾음, 없으면 내 자리가 있는 사업장).
- 날짜 버튼을 누르면 달력이 뜨고, "2026년 10월"을 누르면 월 → 연도 순으로 넓게 볼 수 있습니다.
  키보드: 화살표(하루·한 주), PageUp/PageDown(한 달, Shift면 한 해), Home/End, Enter, Esc.
- 예약은 모두 팝업에서 합니다. 머리글의 "예약하기"나 현황표의 빈 칸(그 시각부터 1시간)을 누르면 뜹니다.
  마우스로 빈 칸을 끌면 끈 만큼(오른쪽·왼쪽 모두, 다른 예약·지난 시간·최대 시간 앞까지) 고르고, 손을 떼면 그 시간으로
  팝업이 뜹니다. 끄는 동안 표 위에 "접견실 101 10:00–12:00"처럼 보이고 Esc로 그만둡니다. 터치는 누르기만(밀면 표가 넘어감).
  팝업은 화면 폭에 맞춰 커지고 작아집니다: 넓으면 두 단(왼쪽 회의실·시간·제목, 오른쪽 AI 추천·참석자),
  좁으면 한 단, 휴대폰에서는 아래에서 올라오는 시트. 창 크기를 바꿔도 팝업과 입력값은 그대로입니다.
- 예약하지 않고 팝업을 닫으면(닫기·X·Esc·바깥 누르기) 고른 칸과 쓰던 내용을 모두 비웁니다. 다음에 열면 빈 폼이고,
  고치던 예약이면 고치기를 그만둡니다. "새로 쓰기"는 제목·참석자를 비우고 방금 고른 회의실·시간은 남깁니다.
- "예약 확정"은 막아 두지 않고, 누르면 빠진 것(회의실·시간·제목)이나 겹침을 알려 줍니다. 정원을 넘으면 한 번 더 확인합니다.
- 시각 목록에는 차 있는 시각도 "(예약 있음)"으로 보입니다(고를 수는 없음). 회의실을 바꿔도 시간은 그대로 두고,
  그 시간에 차 있으면 경고와 함께 그 시간에 비어 있는 회의실을 추천합니다.
- 반복 예약은 몇 회인지 미리 보여 주고, 몇 날만 겹치면 "겹치는 날 빼고 예약"을 할 수 있습니다.
- 예약 고치기: 자세히 보기의 "수정" → `/rooms?date=…&edit=예약ID` 로 같은 폼이 채워져 열립니다 (반복은 그 회차만).
- 예약 현황표는 Tab 한 번으로 들어가 방향키·Home·End로 칸을 옮깁니다. 시간 머리줄은 표를 내려도 보이고,
  옆으로 넘치면 안내가 뜹니다. 오늘이면 지금 시각 쪽으로 밀어 둡니다. 운영 시간 밖에는 회의실 카드 대신 한 줄 안내.
- 시작·종료는 각각 [날짜] [시각]입니다. 여러 날에 걸쳐 잡을 수 있습니다 (최대 7일, 예: 10-26 10:00 ~ 10-28 11:00).
  시작·끝 시각은 각각 08:00~20:00 사이, 30분 단위. 종료일을 다른 날로 고르면 그 기간에 이미 잡힌 예약을 서버에 물어서
  바로 보여 주고, 겹치면 "예약 확정"이 꺼집니다. 여러 날 예약은 반복할 수 없습니다.
- 현황표에서 여러 날 예약은 날마다 그 날에 걸친 만큼 칠해지고("3일 예약"), 누르면 전체 기간이 나옵니다.
- 참석자 칸에는 실제로 회의에 들어가는 사람만 넣습니다. 예약하는 나는 "나 · 예약한 사람" 칩으로 기본 참석이고,
  비서처럼 예약만 해 주면 그 칩을 빼면 됩니다("나도 참석"으로 되돌림). 정원 비교·참석자 수도 실제 들어가는 사람 기준.
- 이름·사번뿐 아니라 팀·본부 이름으로도 사람을 찾습니다. "총무"처럼 팀 이름을 쓰거나 `$총무팀`이면 "총무팀 n명 모두 넣기"가
  뜨고, 누르면 팀 사람이 **한 명씩** 칩으로 들어갑니다 (나·이미 있는 사람은 건너뜀). 팀으로 넣은 사람은 팀별로 모아
  보여 주고, 안 올 사람만 ✕로 빼거나 "모두 빼기"로 한 번에 뺍니다. 본부(`$경영지원본부`)는 아래 팀 사람까지.
  그 시간에 다른 일정이 있는 사람은 칩에 빨간 "!"가 붙습니다.
- 현황표의 예약을 누르면 자세히 보기 팝업이 뜹니다 (만든 사람이면 거기서 수정·취소, 반복 예약은 "이 회차만 / 이후 모두").
- 참석자 칸에 "총무"처럼 팀 이름을 쓰면 맨 위에 "총무팀 전체"가 함께 뜹니다. 나를 고르면 주최자는 자동 포함이라고 알려 줍니다.
- 층 필터는 마지막으로 고른 층을 쿠키(`officemap_rooms_floor`)에 남겨서, 다시 들어와도 그 층으로 엽니다
  (`?floor=층ID`가 있으면 그 층). 조건에 맞는 회의실이 없으면 "조건 초기화".
- 날짜를 바꿔도 작성 중인 내용은 남고, 그날 그 시간이 차 있으면 폼이 알려 줍니다.
- 화면을 열어 둔 채로도 시계를 따라갑니다: "지금" 선·지난 칸·오늘 단추가 브라우저 시각으로 움직이고(`slots.ts` `liveDay`),
  날짜가 바뀌면 다시 읽습니다. 내 예약도 "내일"이 "오늘"로 바뀌고 끝난 회의는 예정에서 빠집니다.
- 다른 탭·창에서 먼저 고친 예약을 오래된 폼으로 저장하면 서버가 거절하고(`expected_updated_at`, 409 `CHANGED_ELSEWHERE`)
  "최신 내용 불러오기"로 다시 채웁니다.
- 로그인이 끊긴 채 예약 확정을 누르면 쓰던 내용을 이 탭에 맡겨 두고(`rooms/draftStore.ts`, 30분) 다시 로그인하면 채워 줍니다.
- "나" 칩도 그 시간에 내가 들어가는 다른 회의·휴가가 있으면 "!"(`GET /api/reservations/mine/clash`). 고치는 예약 자신은
  겹침으로 세지 않습니다(직원 검색·팀원 목록에 `exclude`).
- 그 시간에 비어 있는 회의실 추천은 인원이 들어가는 방 → 가까운 층 → 작은 방 순입니다.
- 범례 "내 회의 (예약·참석)"는 내가 예약했거나 참석하는 회의이고, 블록에 "내 예약" / "참석"이 따로 보입니다.
  끌어서 고를 때 표 끝에 닿으면 옆으로 넘어갑니다. 달력은 팝업 아래 단추에 가리지 않게 화면 기준으로 띄웁니다.
- 회의실 승인 절차는 없습니다. AI 추천 칸은 아직 틀만 있습니다.

## 내 정보 (`/profile`)

- 왼쪽 메뉴 "내 정보"(또는 계정 메뉴). 사진, 부르는 이름(영문 이름·별칭), 한 줄 소개, 하는 일(1000자), 업무 키워드(15개)를
  스스로 고칩니다. 사진은 브라우저에서 가운데를 정사각형으로 잘라 320px JPEG로 만들고, 미리 보고 "이 사진으로"를 눌러야
  올라갑니다("사진 지우기"도 한 번 묻습니다). 같은 키워드·20자 넘는 키워드·15개 초과는 이유를 알려 주고 입력값을 남깁니다.
  저장하지 않은 채 다른 화면으로 가려 하면 한 번 묻습니다.
- 이름·사번·부서·직급·이메일·내선은 인사 정보(조직도)라 보기만 합니다. 부르는 이름은 인사 이름 옆에 함께 보여서,
  다른 사람 이름으로 바꿔 혼동을 주는 일이 없게 했습니다.
- 오른쪽 "동료에게 이렇게 보여요"에 자리 카드 모양이 바로 보입니다. 저장하면 자리 카드·직원 검색·왼쪽 아래 내 사진에 반영됩니다.
- 하는 일·키워드는 직원 검색에 쓰이고, 나중에 AI 도우미가 담당자를 찾을 때 참고합니다.

## 내 재실 상태 (초안)

- 왼쪽 메뉴 "내 재실 상태" → `/presence`. 디자인 시안의 상태·메시지·자동 해제 폼에 더해,
  지금 내 상태(크게), 내 자리, 오늘 내 일정, 우리 팀 재실 현황을 보여 줍니다.
- 팀 현황은 상태별 개수 버튼으로 거를 수 있고, 누가 상태를 바꾸면 새로고침 없이 바로 바뀝니다.
- 상태는 "자리에 있어요"(재실·방해 금지·회의 중·잠시 자리 비움)와 "자리에 없어요"(외근·출장·재택·교육·휴가·부재) 두 묶음으로
  고릅니다. 자리에 있는 상태는 30분·1시간·퇴근 시처럼 시간 단위로, 자리에 없는 상태는 "오늘까지"·"마지막 날 고르기"(달력, 1년 안)로
  풀리게 합니다. 휴가·출장·교육을 고르면 "마지막 날 고르기"가 먼저 골라지고, 그날 다음 날 0시(KST)에 풀립니다
  (서버 `duration: "UNTIL_DATE"`, `until`). 메시지에 "급한 일은 김OO 과장에게"처럼 남기면 자리 카드에 기간과 같이 보입니다.
- 머리글 "내 상태" 패널은 높이 560px까지(화면이 낮으면 남은 화면만큼)이고, 상태·메시지·자동 해제 칸만 그 안에서
  스크롤합니다(제목, "저장하면 …" 안내, 저장 단추는 늘 보임. 휴대폰 아래 시트도 안에서 스크롤).
- 상태 바꾸기 폼은 머리글 "내 상태" 패널과 같은 컴포넌트(`PresenceForm`)입니다. 저장된 상태로 채워지고
  (해제 시각이 걸려 있으면 "그대로 (21:58)"이 골라져 있어 메시지만 고쳐도 해제 시각이 바뀌지 않음),
  상태가 없으면 아무것도 고르지 않은 채로 엽니다. 고른 자동 해제가 언제 풀리는지 미리 보여 줍니다.
  상태를 바꾸면 손대지 않은 앞 메시지는 비웁니다. 상태가 없을 때 자동 해제 기본값은 "오늘 자정"이고, 자정까지 1시간이
  안 남았으면 "1시간 뒤"입니다. 팀 현황에 "상태 없음" 개수도 있습니다. "오늘 남은 일정"은 끝난 회의가 바로 빠지고 자정에 다시 읽습니다.

## 내 예약 (초안)

- 왼쪽 메뉴 "내 예약" → `/reservations`. 내가 만들었거나 초대받은 예약을 날짜별로 묶어 보여 줍니다.
- 위에 요약(오늘 남은 회의, 7일 안, 내가 만든), 탭(예정 / 지난 예약 30일), 역할 필터(전체·내가 만든·초대받은).
- 최근 7일 안에 취소된 회의는 예정 목록에 "취소됨"(줄 그음)으로 남아서, 초대받은 사람도 취소된 것을 압니다.
- 항목을 누르면 회의실 화면과 같은 자세히 보기 팝업이 뜨고, 만든 예약은 거기서 수정·취소합니다.
- 다른 사업장에도 같은 이름의 층이 있으면 회의실 앞에 사업장 이름을 붙입니다("QA 테스트 센터 1F QA 소회의실").
  반복 예약의 기간은 취소되지 않은 회차만으로 보여 줍니다.

## 관리자 페이지

- 주소 `/admin`(로그인 전이면 `/admin/login`)으로 들어가 관리자 비밀번호로 따로 로그인합니다. 관리자 ID는 사번이고,
  최종 관리자만 사번이 아닌 `admin`으로 들어옵니다(로그인 칸이 숫자만 받지 않음). 최종 관리자는 부서가 없어 계정 칸에 역할만 보입니다.
- 계정 메뉴의 "관리자 비밀번호 변경"(`/admin/password`, 직원 화면 비밀번호와 따로). 권한을 받으며 임시 비밀번호를 받은 관리자는
  관리자 페이지의 어느 화면으로 가든 이 화면으로 먼저 오고(바꾸기 전에는 다른 관리자 API가 403 `PASSWORD_CHANGE_REQUIRED`),
  바꾸면 가려던 화면으로 갑니다. 규칙은 직원 비밀번호와 같습니다(8자 이상, 영문+숫자, 사번이 들어가지 않음).
- 직원 화면과 관리자 페이지는 완전히 나눕니다: 직원 화면(로그인 화면 포함)에는 관리자 페이지로 가는 링크가 없고,
  관리자 페이지(관리자 로그인 포함)에도 직원 화면으로 가는 링크가 없습니다. 없는 주소(404)도 보던 쪽 첫 화면으로만 안내합니다.
- 로그아웃은 그쪽 로그인만 끝냅니다: 관리자 페이지에서 로그아웃해도 직원 화면 로그인은 그대로이고, 반대도 같습니다.
- 관리자 로그인이 안 되어 있으면 `/admin/login`으로, 15분 넘게 쓰지 않았거나 권한이 바뀌었으면
  `/admin/login?reason=expired`로 보내 이유를 알려 줍니다. 이 안내는 한 번만: 로그인 화면이 보여 준 뒤 주소에서 `reason`을
  지우고(`app/login/ForgetLoginReason.tsx`) 끊긴 로그인 쿠키도 지워서(`/api/admin/auth/me`·`/api/auth/me`가 끊겼으면 쿠키를
  지움), 새로고침하거나 창을 다시 열어도 다시 뜨지 않습니다. 직원 로그인 화면도 같습니다.
- 왼쪽 메뉴: 사업장·권한, 조직도, 좌석 배치 편집, 도면 편집·팀 이사(층 관리자 이상만), 인사이동(최종·전사 관리자만).
- **사업장·층**: 전사 관리자는 머리의 "사업장 추가"와 사업장마다 "사업장 고치기"(이름·본사/센터·주소, 층이 없으면 닫기).
  사업장 관리자 이상은 "+ 층 추가"(이름, 용도, 놓을 자리 = 층 버튼 순서)와 층마다 "층 고치기"(이름·용도·순서, 좌석·회의실이
  없을 때만 "층 없애기", 없애면 그 층의 빈 구역·초안·층/구역 관리자 권한도 정리). 새 층은 도면 관리에서 초안을 만들어 게시합니다.
  닫은 사업장 이름으로 다시 추가하면 그 사업장을 다시 엽니다. 없앤 층·닫은 사업장의 이름은 다른 층·사업장 이름으로 쓸 수 있습니다
  (이름 겹침은 대소문자를 가리지 않고 쓰는 것끼리만 봅니다). 입력이 규칙에 맞지 않으면 서버가 알려 준 규칙을 그대로 보여 줍니다.
- **조직도** (`/admin/org`): 왼쪽 부서 나무(인원 수, 접고 펴기, "없앤 부서도"), 오른쪽 고른 부서와 팀원(자리·내선·휴직·관리자·
  임시 비밀번호 표시). 전사 관리자만 고치고 다른 관리자는 보기만 합니다.
  - 나무 위 "이름·사번으로 사람 찾기": 고르면 그 사람의 부서를 펼쳐 열고 팀원 줄을 표시해 화면 가운데로 보여 줍니다.
  - 조직도 팀원 표는 이름 가나다순으로 시작합니다. "직급순으로"를 누르면 서버 순서인 직급(부장 → 수석부부장 → 부부장 → 차장 →
    과장 → 대리 → 사원 → 수습직원 → 사무사원) → 입사연도(사번 앞자리) → 입사일 순 (`app/people_order.py`, 내 팀 현황·회의 참석자·

  도면은 둘레로 1.5 m씩 넓음. 새 책상 기본 크기 1.6 × 0.8 m, 도면 파일로 만든 초안은 가져올 때 정한 책상 크기) · 다른 층 복제 ·
  보관본에서 다시 시작. 게시 기록도 여기 있습니다.
- 그리기: 벽·기둥·회의실·공간(7종)·주 출입구·출입구는 끌어서 사각형으로 그리고(누르기만 하면 기본 크기), **선 벽**은 끌어서
  선으로 그립니다(Shift: 45도씩, 누르기만 하면 4 m 가로 선). 책상 묶음(1인·마주보기 6석·한 방향 4석·팀 섬 12석)은 누른 곳에
  놓습니다. 그린 뒤에는 선택 도구로 돌아갑니다. 칸 맞추기(도구 줄의 "칸에 맞추기"와 칸 크기 0.1·0.5·1 m, 기본 0.1 m: 끌기·크기 바꾸기·방향키가 그 간격으로,
  Shift+방향키는 1 m, 끄면 1 cm 단위). 도면 크기 숫자 칸의 위아래 화살표도 0.1 m씩입니다. 도면 가장자리에 놓은 책상 묶음은 도면 안으로 당기고,
  놓기·복제(Ctrl+D)·붙여넣기가 다른 요소와 겹치면 알려 줍니다. 숫자 칸은 입력하는 동안 허용 범위를 보여 주고, 범위 밖이면
  원래 값을 남겼다고 알려 줍니다.
- 고른 요소는 끌어서 옮기고 손잡이 8개로 크기를 바꿉니다(선 벽은 양 끝 동그란 손잡이). 오른쪽 칸에서 위치·크기(선 벽은 양 끝·길이),
  공간 종류·이름표, 회의실 이름·정원·장비, 출입구 이름표·주 출입구, 책상 묶음의 모양(마주보기·한 방향)·줄·칸, 칸마다 책상 두기·
  좌석 번호·"이 책상만 반대쪽을 보고 앉기", "번호 다시 매기기"를 고칩니다.
- **모양**: 벽·선 벽·회의실·공간·출입구는 선 굵기(cm), 회의실·공간·출입구는 이름표 글자 크기(%)·굵게. 직원 화면에도 같은
  비율로 그려집니다("기본 굵기·글자 크기로"로 되돌림).
- **책상 방향·크기**: 책상 묶음을 "↺ 왼쪽으로 / ↻ 오른쪽으로"(단축키 R / Shift+R) 90도씩 돌립니다. 같은 칸(좌석)이라 앉은 사람은
  그대로이고, 게시하면 직원 화면 좌석도 돌아갑니다(세로 좌석은 이름을 세로로). 책상 하나 크기(가로·세로, m)도 묶음마다 바꾸고
  (도면에 보이는 대로: 90도 돌린 묶음은 책상의 두 변이 바뀌어 보임), 요약 칸의 "새 책상 기본 크기"는 새로 놓는 묶음에 씁니다.
- **여러 개 고르기**: Ctrl(⌘)·Shift를 누른 채 누르면 더하거나 빼고, 빈 곳에서 끌면 사각형 안에 다 들어온 요소를 고릅니다
  (Ctrl을 누르고 끌면 더함). Ctrl+A 모두. 고른 것은 함께 끌거나 방향키로 옮기고, 오른쪽에서 왼쪽 x·위 y, 줄 맞추기(왼쪽·가로
  가운데·오른쪽·위·세로 가운데·아래), 간격 똑같이(3개 이상), 선 굵기·글자, 책상 방향·크기를 함께 바꾸며 복제·복사·지우기도 함께.
- **크기 보기**: 위·왼쪽 눈금자(미터, 포인터 자리와 고른 것의 범위 표시), 고른 것 아래 "폭 × 높이 m"(선 벽은 길이),
  "치수 보기"를 켜면 요소마다 크기. 도구 줄의 "50 × 30 m" 단추와 요약 칸에 사무실 크기·넓이.
- **선 벽 잇기** (파워포인트 연결점처럼): 선 벽 도구를 고르면 이음 자리(다른 선 끝·벽 모서리)가 작은 동그라미로 보이고,
  그리거나 끝을 끌다 가까이 가면 초록 동그라미(점)·마름모(벽·선 위)와 함께 붙습니다. 벽(사각형)에는 벽 띠 가운데 선에 붙어
  선 끝이 벽 밖으로 삐져나오지 않습니다. 다른 점과 가로·세로가 맞으면 초록 점선 안내선이 뜨고 그 줄에 맞춥니다.
  이어진 끝을 끌면 붙어 있는 선이 함께 움직여 벽이 끊기지 않고, Alt를 누르고 끌면 붙이지 않거나 떼어 냅니다.
  선 벽을 통째로 옮길 때도 끝이 다른 벽에 가까우면 붙습니다. 선 벽 끝은 네모로 그려 모서리에서 빈틈 없이 만납니다.
  가로·세로 선은 돌리지 않은 사각형으로 그려(비스듬한 선만 돌림) 확대해도 이음매가 1px도 어긋나지 않고, 붙인 자리는 1 mm 단위입니다.
- **선 정리**: 도구 줄의 "선 정리…"(또는 선 벽 여러 개를 고른 도구 막대). 기운 선을 가로·세로로 곧게(기본 5도 이내),
  가까운 끝을 잇고(기본 30cm, 벽 가운데 선·다른 선 가운데(T자)에도), 원하면 선 벽(과 벽) 굵기를 한 값으로 맞춥니다.
  바뀌는 선 수를 미리 보여 주고, 한 번에 되돌릴 수 있습니다.
- **도구 막대**: 요소를 고르면 바로 위(위쪽 끝이면 아래)에 도구 막대가 뜹니다. 왼쪽·오른쪽으로 돌리기(책상은 의자 방향,
  사각형은 가로·세로, 선은 가운데 기준, 여러 개면 함께 가운데 기준), 선 하나면 "가로·세로로 곧게", 선 여러 개면 "선 정리",
  여러 개면 줄 맞추기 6가지, 복제·복사·지우기. 단축키는 단추 설명에 있습니다.
- **도면 파일로 시작**: 시작 화면의 "도면 파일 고르기…". 그림(PNG·JPG·WEBP)·PDF(쪽마다, 60쪽까지)·엑셀 .xlsx(시트마다),
  50MB까지. 왼쪽 쪽 목록에서 쪽마다 쓸 층을 고르고(글자·시트 이름·파일 이름의 "8F"·"3층"·"지하 1층"·"B1"로 저절로,
  "순서대로 층 맞추기", "이 쪽만 지금 층에"), 가운데 쪽 그림에서 끌어 도면 부분을 고르고(처음엔 도곽 안쪽을 저절로),
  오른쪽에서 실제 크기(축척 1:N은 PDF 종이 크기로 셈, 도면에 "S=1/200"이 있으면 저절로 · 가로 길이 m · 두 점 찍고 실제 길이)와
  찾을 것(벽으로 볼 선 굵기, 짧은 선 빼기, 선 진하기, 두 줄 벽, 기둥, 이름 쓰인 방, 책상, 도곽 빼기)을 정합니다. 찾은 벽(빨강)·
  기둥·회의실(파랑)·공간(초록)·책상(노랑)이 그림 위에 겹쳐 보입니다. "N개 층 초안 만들기"는 층마다 초안과 밑그림을 만들고,
  지금 층이 있으면 그 초안을 엽니다. 파일은 브라우저 안에서만 읽습니다.
- **밑그림**: 도면 파일 그림을 요소 밑에 깔아 보며 고칩니다(편집 화면에서만, 층마다 하나). 도구 줄 "밑그림" 체크로 숨기기,
  "밑그림…"으로 자리·크기(m)·진하기·다른 파일·지우기. 밑그림이 없으면 "도면 파일 깔기…"로 지금 초안에 깔고, 원하면 찾은
  요소도 더합니다(밑그림이 도면보다 크면 도면을 넓힘, 되돌리기 한 번).
- **확대·축소**: 트랙패드 핀치(Chrome·Edge·Firefox·Safari)나 Ctrl+마우스 휠로 포인터 자리를 기준으로 25~600%, − / + 단추.
  두 손가락 이동·휠은 스크롤입니다.
- 단축키: Delete 지우기, 방향키는 고른 칸 크기만큼(기본 0.1 m, 칸 맞추기를 끄면 0.1 m, Shift는 1 m), R / Shift+R 책상 돌리기, Ctrl+A 모두 고르기,
  Ctrl+Z / Ctrl+Shift+Z·Ctrl+Y, Ctrl+D 복제, Ctrl+C / Ctrl+V, Esc.
- 책상에는 지금 앉은 사람이 점(●)으로, 새 책상은 파란 점선으로, 게시를 막는 문제(같은 좌석 번호 등)는 빨간 테두리로 보입니다.
  앉은 사람이 있는 책상이나 예약이 남은 회의실을 지우면 바로 알려 줍니다.
- 고치면 1.5초 뒤 자동 저장. 다른 관리자가 편집 중이면 띠와 함께 보기만 하고 "편집 넘겨받기"로 가져옵니다.
  넘겨준 쪽 화면은 10초 안에(편집 중 표시 간격) 보기만 하는 화면으로 바뀝니다.
  다른 화면이 먼저 저장했으면 "다시 불러오기"·"내 것으로 덮어쓰기"를 고릅니다.
- "도면 게시…": 바뀌는 것 요약, 게시를 막는 문제("도면에서 고치기"), 책상이 없어지는 사람(기본 미배치, 사람마다 새 자리 또는
  "모두 추천 자리로"), 예약이 남은 회의실(다른 회의실로 옮기기·모두 취소, 정해야 게시), 게시 메모.
- 화면 폭에 따라 세 단(그리기 | 도면 | 속성) → 두 단(도면 | 속성·그리기) → 한 단으로 바뀝니다. 경계 폭(1024px 등)에서 단 수가
  바뀌며 스크롤 막대가 생겼다 없어져 화면이 계속 깜빡이지 않도록, 단을 늘릴 때는 24px 여유를 넘어야 늘립니다(`lib/columns.ts`, 좌석 배치도 같음).
- **게시 날짜 지정**: 게시 점검의 "언제 게시할까요"에서 날짜(내일~1년)를 고르면 그날 0시에 서버가 게시합니다. 예약한 초안은
  고칠 수 없고, 편집 화면은 예약 내용(그날 책상이 없어지는 사람과 고른 자리, 없어지는 회의실과 예약 처리)을 보여 주며
  "예약 취소하고 고치기"로 되돌립니다. 그날 게시되면 열려 있던 화면도 저절로 바뀝니다.
- **도면 크기**: 아무것도 고르지 않았을 때 요약 칸의 "도면 크기"(가로·세로, 10~300 m). 요소는 그 자리에 두고 도면만 넓히거나
  줄이며 되돌리기가 됩니다. 책상 크기는 그대로라, 도면이 커지면 직원 화면 좌석이 작게 보입니다. "요소도 같은 비율로 바꾸기…"
  (또는 도구 줄의 크기 단추)는 벽·회의실·공간을 같은 비율로 늘리거나 줄이고, 책상은 실제 크기 그대로 자리만 옮기거나(기본)
  책상 크기도 같이 바꿉니다. 가로·세로 비율 그대로도 고를 수 있습니다.
- **복사·붙여넣기**: 요소(여러 개도)를 고르고 Ctrl+C(오른쪽 "복사"), 같은 브라우저에서 다른 층 도면 편집 화면을 열고 Ctrl+V(도구 줄
  "붙여넣기"). 다른 층이면 같은 자리에, 같은 층이면 1 m 옆에 놓고, 좌석 번호가 겹치면 새 번호를 붙입니다. 보기만 할 때도 복사는 됩니다.
- "내보내기": 지금 초안을 PNG·PDF로 (앉은 사람은 지금 게시본 기준). 선 벽·출입구·선 굵기·글자 모양·돌린 책상이 그대로
  그려지고, 아래에 축척 막대와 도면 크기가 붙습니다.
- 직원 화면에서는 축척 막대를 도면 위에 겹쳐 그리지 않고 도면 아래 범례 줄("빗금 = …" 옆)에 둡니다. 지금 배율에서 44 px 이상이 되는
  가장 짧은 길이(1·2·5·10… m)를 그려 확대·축소하면 따라 바뀝니다. 도면 크기 글자는 보여 주지 않습니다(`PlanShapes.ScaleLegend`).

## 팀 이사 (`/admin/moves`)

- 왼쪽 메뉴 "팀 이사" (목적지 층의 층 관리자 이상).
- 1 옮길 팀 → 2 옮길 층(구역을 누르면 그 구역 빈 자리를 모두 고르고, 오른쪽 도면에서 빈 자리를 눌러 더하거나 빼기) →
  3 사람과 자리 맞추기("순서대로 맞추기": 지금 자리 번호 순으로 고른 자리 번호 순에, 사람마다 자리·옮기지 않음·미배치로) →
  4 언제(지금 또는 날짜)·구역 이름표(고른 자리 구역을 이 팀 구역으로)·메모 → "지금 옮기기" / "이사 예약하기".
- 오른쪽 도면에 고른 자리는 파란 테두리와 맞춘 사람 이름으로 보입니다.
- 끝나면 목적지 층과 옛 층의 배치 화면으로 가는 단추가 나옵니다 (옛 구역은 거기서 정리). 날짜를 정한 이사는 배치 화면 요청
  목록에서 "예정 취소"로 함께 되돌립니다.

## 인사이동 (`/admin/personnel`)

- 왼쪽 메뉴 "인사이동"·관리자 첫 화면 "인사이동" 단추 (최종·전사 관리자, 조직도와 같음).
- **엑셀 읽기** (`lib/personnelFile.ts`, 브라우저에서 exceljs): .xlsx와 CSV(UTF-8, 깨지면 EUC-KR). 숨긴 시트는 건너뛰고,
  위에서 20줄 안에서 사번 + 새 부서(또는 직급·직책) 머리글이 있는 줄을 찾습니다. 머리글은 빈칸·괄호를 빼고 비교하고
  여러 이름을 받습니다(사번/직원번호, 이름/성명, 현 부서/현소속/전 부서, 새 부서/발령부서/신소속, 직급/직위, 직책).
  "부서"·"소속" 열이 하나뿐이면 새 부서로 봅니다. 사번도 새 부서도 없는 줄(빈 줄·합계)은 건너뜁니다. 2,000줄까지.
  올리는 칸 위 양식 카드의 "양식 내려받기"는 "발령"(머리글만)·"안내"(쓰는 법·예시) 두 시트 양식을 만듭니다.
  목업 데이터로 해 볼 엑셀: `docs/samples/인사이동_발령_목업.xlsx`.
- **확인** (서버 미리 보기): 줄마다 반영 · 확인(알림이 있지만 반영) · 그대로(바뀌는 것 없음) · 빠짐(반영 안 함)과 이유,
  지금 반영하면 앉을 새 자리(또는 미배치 이유), 부서별 들어옴·나감·새 자리·미배치(팀 구역 없는 부서 표시). "확인·빠짐"
  "빠지는 줄"만 걸러 보기. 자리 배치 방식을 바꾸면 다시 확인합니다.
- **반영**: 자리 배치(새 팀 구역 빈 자리에 자동 / 모두 미배치로), 반영 시점(지금 / 발령일 0시, 내일부터 1년 안),
  기록에 남길 이름(기본은 파일 이름) → 확인 창 → 반영(또는 예약). 끝나면 결과와 "좌석 배치 편집으로"(미배치 정리).
- **기록**: 예약 · 반영됨 · 취소됨 · 실패, 사람 수와 부서 이동·새 자리·미배치, 만든 사람·날짜. "사람별 결과"로 펼치고,
  예약은 "예약 취소"(한 번 더 확인).

## 자리 배치 실시간 반영 (직원 화면)

- 보고 있는 층의 배치가 바뀌면 바로 다시 읽고(확대·선택은 그대로) "7F 자리 배치가 바뀌었어요 (3석)"을 잠깐 띄웁니다.
- 내 자리가 바뀌면 어느 층을 보고 있든 "내 자리가 바뀌었어요: 7F B-17 · 보기"(날짜를 정한 변경이면 그 날짜)를 띄웁니다.
- 도면이 새로 게시되면 "7F 도면이 새로 게시됐어요 · 5초 뒤 새 도면으로 보여 드려요 · 지금 보기" 배너를 띄우고
  5초 뒤 저절로 새로 읽습니다. 게시 한 번에 좌석 알림도 여러 개 오는데, 배너가 떠 있는 동안에는 따로 다시 읽지 않습니다.
- 날짜를 정해 둔 변경은 그 시각(`next_change_at`)에 다시 읽어서 바뀝니다.

## 재실 상태 실시간 반영

- 누가 상태를 바꾸면 서버가 바로 알려 주고(SSE), 새로고침 없이 도면·오른쪽 패널·내 상태 버튼이 바뀝니다.
- 실시간 연결은 탭이 보일 때만 엽니다. 브라우저는 같은 주소에 동시 연결을 6개까지만 열어서(HTTP/1.1), 탭마다 연결을
  잡고 있으면 탭을 여러 개 열었을 때 페이지 이동이 빈 연결을 기다리며 멈췄습니다("Rendering…"). 숨긴 탭은 연결을 닫고,
  다시 보이면 새로 붙으면서 그사이 바뀐 것을 다시 읽습니다 (`lib/eventStream.ts`, 관리자 화면도 같음).
  확대 배율, 고른 자리, 스크롤 위치는 그대로입니다.
- 서버에서 읽은 데이터(`fetched_at`)보다 나중에 온 알림만 덮어씁니다.
- 연결이 끊기면 다시 붙고, 그 사이 놓친 변경이 있을 수 있어 화면 데이터를 한 번 다시 읽습니다.
- 자동 해제 시각이 되면 화면 데이터를 다시 읽어서 상태가 사라집니다.
