# OfficeMap 화면 (Next.js)

```bash
npm install
cp .env.example .env.local   # Windows: copy .env.example .env.local
npm run dev                  # http://localhost:3000
```

API 서버(`server/`, uvicorn)가 `http://localhost:8000`에서 떠 있어야 로그인이 됩니다.
브라우저는 `/api/...`로만 요청하고, Next.js가 `API_URL`로 넘겨줍니다(`next.config.ts`).

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 (코드 바꾸면 바로 반영) |
| `npm run build` / `npm start` | 운영용 빌드와 실행 |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript 검사 |

## 왼쪽 메뉴 접기

- 햄버거 버튼으로 접고 펴면 본문 폭이 그만큼 늘고 줄며, 도면도 같이 커지고 작아집니다.
- 고른 상태는 `officemap_sidebar` 쿠키에 남아 새로고침해도 유지됩니다.
- 한 번도 고르지 않았으면 펼칩니다.
- 휴대폰(720px 이하)에서는 왼쪽 메뉴가 숨고, 위쪽 막대의 햄버거로 서랍처럼 엽니다. 바깥을 누르거나 Esc,
  메뉴를 고르면 닫힙니다 (화면 폭을 늘 차지하던 아이콘 줄이 없어 본문이 넓어집니다).
- 아직 화면이 없는 메뉴(AI 도우미, 좌석 배치 편집 등)에는 "준비 중"이 보입니다.
- 아래 사용자 칸의 계정 메뉴는 body에 띄워서, 메뉴를 접었을 때도 아바타 오른쪽에 가려지지 않고 뜹니다.

## 도면 확대·축소

- 버튼(－ / ＋ / 맞춤) 외에 트랙패드 두 손가락 벌리기·오므리기로 50%~300% 사이를 확대·축소합니다.
  손가락이 있는 곳을 기준으로 커지고, 두 손가락으로 밀면 그대로 스크롤됩니다.
- Chrome·Edge·Firefox는 핀치가 `ctrlKey`가 붙은 `wheel` 이벤트로 오고(Ctrl+마우스 휠도 같음),
  Safari는 `gesturechange`의 `scale`로 옵니다. 도면 위에서만 막아서 브라우저 화면 전체는 커지지 않습니다.
- 휴대폰 터치 핀치는 아직 지원하지 않습니다 (브라우저 확대가 그대로 동작).
- 확대해서 도면이 영역보다 커지면 마우스로 잡고 끌어서 옮깁니다(손 모양 커서). 5px 넘게 움직여야 끌기로 봐서,
  그냥 누르면 자리 고르기 그대로입니다.
- 자리 이름·재실 표시·의자는 도면 폭 기준(cqw) 크기라 확대하면 같이 커집니다.

## 자리 정보 카드와 검색

- 자리에 마우스를 0.7초 올려 두면 그 사람의 이름·팀·재실 상태·내선이 카드로 뜹니다 (키보드로 자리에 가도 같음).
- 오른쪽 패널이 도면 아래로 내려가는 좁은 화면에서는 자리를 누르면 같은 카드가 자리 옆에 고정돼 뜹니다.
  Esc, 닫기 버튼, 바깥을 누르면 닫힙니다.
- 머리글 검색창에 이름·팀·사번을 치면 아래에 결과 목록이 뜹니다. 고르면 그 사람 층으로 가서 자리를 가운데로
  가져오고 골라 둡니다. 다른 층이면 주소가 `/?floor=층ID&seat=자리ID`로 바뀝니다.
- 재실 표시는 색과 모양을 둘 다 다르게 했습니다: 방문 가능 초록 원, 방해 금지 빨간 원에 흰 줄,
  회의 중 보라 네모, 부재 회색 점선 원, 상태 없음 빈 회색 원 (범례·거르기·층 요약 숫자에도 "상태 없음"이 있음).
- 카드·오른쪽 패널에 언제 바꾼 상태인지("12분 전 변경")와 해제 시각이 보여서 오래된 상태를 알아볼 수 있습니다.
- 내 자리는 "나" 표시와 굵은 테두리. 내 자리를 누르면 "내 재실 상태 바꾸기" 바로가기가 있습니다.
- 휴대폰에서 자리를 누르면 정보가 화면 아래 시트로 뜹니다 (도면 가장자리에서 잘리지 않게).
- 상태 필터를 걸면 도면 위에 "필터 적용 중 · 모두 보기"가 뜹니다 (다른 층으로 가도 유지되므로).
- 도면의 회의실을 누르면 회의실 화면이 그 층으로 열립니다. 자리가 아직 없는 사람은 우리 팀 층이 열리고 안내가 뜹니다.
- 키보드: "도면 건너뛰기" 링크, 고른 자리는 Esc로 해제.

## 회의실 확인·예약

- 날짜 버튼을 누르면 달력이 뜨고, "2026년 10월"을 누르면 월 → 연도 순으로 넓게 볼 수 있습니다.
  키보드: 화살표(하루·한 주), PageUp/PageDown(한 달, Shift면 한 해), Home/End, Enter, Esc.
- 예약은 모두 팝업에서 합니다. 머리글의 "예약하기"나 현황표의 빈 칸(그 시각부터 1시간)을 누르면 뜹니다.
  팝업은 화면 폭에 맞춰 커지고 작아집니다: 넓으면 두 단(왼쪽 회의실·시간·제목, 오른쪽 AI 추천·참석자),
  좁으면 한 단, 휴대폰에서는 아래에서 올라오는 시트. 창 크기를 바꿔도 팝업과 입력값은 그대로입니다.
- 닫아도 작성 중인 내용은 남고 버튼이 "작성 중인 예약 이어서"로 바뀝니다. "새로 쓰기"는 제목·참석자를 비우고
  방금 고른 회의실·시간은 남깁니다. 다른 칸을 눌러 새로 시작하면 "앞에서 쓰던 제목·참석자를 이어서 쓰는 중"이라고 알려 줍니다.
- "예약 확정"은 막아 두지 않고, 누르면 빠진 것(회의실·시간·제목)이나 겹침을 알려 줍니다. 정원을 넘으면 한 번 더 확인합니다.
- 시각 목록에는 차 있는 시각도 "(예약 있음)"으로 보입니다(고를 수는 없음). 회의실을 바꿔도 시간은 그대로 두고,
  그 시간에 차 있으면 경고와 함께 그 시간에 비어 있는 회의실을 추천합니다.
- 반복 예약은 몇 회인지 미리 보여 주고, 몇 날만 겹치면 "겹치는 날 빼고 예약"을 할 수 있습니다.
- 예약 고치기: 자세히 보기의 "수정" → `/rooms?date=…&edit=예약ID` 로 같은 폼이 채워져 열립니다 (반복은 그 회차만).
- 예약 현황표는 Tab 한 번으로 들어가 방향키·Home·End로 칸을 옮깁니다. 시간 머리줄은 표를 내려도 보이고,
  옆으로 넘치면 안내가 뜹니다. 오늘이면 지금 시각 쪽으로 밀어 둡니다. 운영 시간 밖에는 회의실 카드 대신 한 줄 안내.
- 시작·종료는 각각 [날짜] [시각]입니다. 여러 날에 걸쳐 잡을 수 있습니다 (최대 7일, 예: 10-26 10:00 ~ 10-28 11:00).
  시작·끝 시각은 각각 08:00~20:00 사이, 30분 단위. 종료일을 다른 날로 고르면 그 기간에 이미 잡힌 예약을 서버에 물어서
  바로 보여 주고, 겹치면 "예약 확정"이 꺼집니다. 여러 날 예약은 반복할 수 없습니다.
- 현황표에서 여러 날 예약은 날마다 그 날에 걸친 만큼 칠해지고("3일 예약"), 누르면 전체 기간이 나옵니다.
- 참석자 칸에는 실제로 회의에 들어가는 사람만 넣습니다. 예약하는 나는 "나 · 예약한 사람" 칩으로 기본 참석이고,
  비서처럼 예약만 해 주면 그 칩을 빼면 됩니다("나도 참석"으로 되돌림). 정원 비교·참석자 수도 실제 들어가는 사람 기준.
- 이름·사번뿐 아니라 팀·본부 이름으로도 사람을 찾습니다. "총무"처럼 팀 이름을 쓰거나 `$총무팀`이면 "총무팀 n명 모두 넣기"가
  뜨고, 누르면 팀 사람이 **한 명씩** 칩으로 들어갑니다 (나·이미 있는 사람은 건너뜀). 팀으로 넣은 사람은 팀별로 모아
  보여 주고, 안 올 사람만 ✕로 빼거나 "모두 빼기"로 한 번에 뺍니다. 본부(`$경영지원본부`)는 아래 팀 사람까지.
  그 시간에 다른 일정이 있는 사람은 칩에 빨간 "!"가 붙습니다.
- 현황표의 예약을 누르면 자세히 보기 팝업이 뜹니다 (만든 사람이면 거기서 수정·취소, 반복 예약은 "이 회차만 / 이후 모두").
- 참석자 칸에 "총무"처럼 팀 이름을 쓰면 맨 위에 "총무팀 전체"가 함께 뜹니다. 나를 고르면 주최자는 자동 포함이라고 알려 줍니다.
- 층 필터는 마지막으로 고른 층을 쿠키(`officemap_rooms_floor`)에 남겨서, 다시 들어와도 그 층으로 엽니다
  (`?floor=층ID`가 있으면 그 층). 조건에 맞는 회의실이 없으면 "조건 초기화".
- 날짜를 바꿔도 작성 중인 내용은 남고, 그날 그 시간이 차 있으면 폼이 알려 줍니다.
- 회의실 승인 절차는 없습니다. AI 추천 칸은 아직 틀만 있습니다.

## 내 재실 상태 (초안)

- 왼쪽 메뉴 "내 재실 상태" → `/presence`. 디자인 시안의 상태 4가지·메시지·자동 해제 폼에 더해,
  지금 내 상태(크게), 내 자리, 오늘 내 일정, 우리 팀 재실 현황을 보여 줍니다.
- 팀 현황은 상태별 개수 버튼으로 거를 수 있고, 누가 상태를 바꾸면 새로고침 없이 바로 바뀝니다.
- 상태 바꾸기 폼은 머리글 "내 상태" 패널과 같은 컴포넌트(`PresenceForm`)입니다. 저장된 상태로 채워지고
  (해제 시각이 걸려 있으면 "그대로 (21:58)"이 골라져 있어 메시지만 고쳐도 해제 시각이 바뀌지 않음),
  상태가 없으면 아무것도 고르지 않은 채로 엽니다. 고른 자동 해제가 언제 풀리는지 미리 보여 줍니다.
  상태를 바꾸면 손대지 않은 앞 메시지는 비웁니다.

## 내 예약 (초안)

- 왼쪽 메뉴 "내 예약" → `/reservations`. 내가 만들었거나 초대받은 예약을 날짜별로 묶어 보여 줍니다.
- 위에 요약(오늘 남은 회의, 7일 안, 내가 만든), 탭(예정 / 지난 예약 30일), 역할 필터(전체·내가 만든·초대받은).
- 최근 7일 안에 취소된 회의는 예정 목록에 "취소됨"(줄 그음)으로 남아서, 초대받은 사람도 취소된 것을 압니다.
- 항목을 누르면 회의실 화면과 같은 자세히 보기 팝업이 뜨고, 만든 예약은 거기서 수정·취소합니다.

## 관리자 페이지

- 직원 로그인 화면 아래 "관리자 페이지" → `/admin/login`. 관리자 비밀번호로 따로 로그인합니다.
  관리자 권한이 있는 직원은 직원 화면 왼쪽 메뉴에도 "관리자 페이지" 입구 하나만 보입니다 (관리 메뉴는 관리자 페이지 안에만).
- 로그아웃은 어디서 하든 이 브라우저의 직원·관리자 로그인을 모두 끝냅니다.
- 관리자 로그인이 안 되어 있으면 `/admin/login`으로, 15분 넘게 쓰지 않았거나 권한이 바뀌었으면
  `/admin/login?reason=expired`로 보내 이유를 알려 줍니다.
- 왼쪽 메뉴: 관리(사업장·권한, 좌석 배치 편집, 도면 편집 — 층 관리자 이상만), 직원 화면(자리·재실 현황).
  계정 메뉴에 맡은 범위가 보입니다. 직원 화면에 로그인해 있으면 관리자 로그인의 사번이 미리 채워집니다.
- 첫 화면(④ 사업장·층·권한): 내 관리 범위, 요약 숫자(전사 관리자는 전체, 그 아래는 내 범위 안: 개인석 배정·자율석·
  회의실·오늘 예약·승인 대기), 사업장별 층 표(입주 팀 칩은 도면 색, 개인석 배정/자율석, 층 관리자, 도면 상태, 최종 수정),
  관리자 권한 체계(내 단계 강조), 관리자 목록.
  버튼은 내 권한으로 할 수 있는 것만 보이고(예: 구역 관리자는 내 층에 "내 구역 배치"만, 나머지는 "조회만"),
  "배치 편집"은 좌석 배치 편집으로 가고, 아직 화면이 없는 버튼(도면 관리 등)은 점선이고 누르면 "준비 중" 말풍선이 뜹니다.
- 표는 옆으로 밀어도 층 칸이 남고, 휴대폰에서는 줄마다 카드로 바뀝니다.
- 자동 로그아웃 1분 전에 아래에 알림("계속 사용")이 뜹니다 (직원 화면도 같음).

## 좌석 배치 편집 (⑤)

- 관리자 첫 화면의 "배치 편집"(구역 관리자는 "내 구역 배치") 또는 왼쪽 메뉴 → `/admin/seating?floor=층ID`.
- 사람을 끌어 빈 자리에 놓으면 배정, 사람 위에 놓으면 자리 교환, 미배치 칸에 놓으면 배정 해제(내가 바꾼 자리면
  원래 앉아 있던 사람이 돌아옴). 끌기가 안 되는 휴대폰·키보드는 미배치 인원을 누른 뒤 자리를 누르거나,
  자리를 골라 오른쪽 "선택한 좌석"에서 배정 직원·좌석 유형(고정석·팀 내 자율석·사용 중지)을 고릅니다.
  배치 도구: 선택·이동 / 자리 교환(두 자리를 차례로) / 배정 해제.
- 바꾼 것은 작업 묶음에 0.8초 뒤 자동 저장되고(직원 화면에는 아직 안 보임), "되돌리기"로 한 단계씩 되돌립니다.
  "직원 화면 미리보기"는 반영하면 보일 모습입니다.
- 반영: 층 관리자 이상·"즉시 반영" 구역 관리자는 "반영하기", "승인 후" 구역 관리자는 "층 관리자에게 승인 요청".
  층 관리자는 요청 목록의 "검토"로 도면 위에서 바뀌는 자리를 보고 승인·반려(사유)합니다.
- 반영 시점 "날짜 지정": 그날 0시부터 바뀝니다. 그때까지 그 자리·사람은 잠기고(날짜 표시), 요청 목록에서 "예정 취소".
  좌석 유형 변경이 섞이면 날짜를 정할 수 없습니다.
- 다른 관리자가 같은 층에 반영하면 화면이 바로 다시 읽고, 내 묶음과 겹친 자리는 빨갛게 "충돌"로 보입니다.
- 화면 폭에 따라 세 단(도구·미배치 | 도면 | 좌석·변경) → 두 단(도면 | 나머지) → 한 단으로 바뀝니다.

## 자리 배치 실시간 반영 (직원 화면)

- 보고 있는 층의 배치가 바뀌면 바로 다시 읽고(확대·선택은 그대로) "7F 자리 배치가 바뀌었어요 (3석)"을 잠깐 띄웁니다.
- 내 자리가 바뀌면 어느 층을 보고 있든 "내 자리가 바뀌었어요: 7F B-17 · 보기"(날짜를 정한 변경이면 그 날짜)를 띄웁니다.
- 도면이 새로 게시되면 "7F 도면이 새로 게시됐어요 · 5초 뒤 새 도면으로 보여 드려요 · 지금 보기" 배너를 띄우고
  5초 뒤 저절로 새로 읽습니다 (도면 편집기는 다음 단계).
- 날짜를 정해 둔 변경은 그 시각(`next_change_at`)에 다시 읽어서 바뀝니다.

## 재실 상태 실시간 반영

- 누가 상태를 바꾸면 서버가 바로 알려 주고(SSE), 새로고침 없이 도면·오른쪽 패널·내 상태 버튼이 바뀝니다.
  확대 배율, 고른 자리, 스크롤 위치는 그대로입니다.
- 서버에서 읽은 데이터(`fetched_at`)보다 나중에 온 알림만 덮어씁니다.
- 연결이 끊기면 다시 붙고, 그 사이 놓친 변경이 있을 수 있어 화면 데이터를 한 번 다시 읽습니다.
- 자동 해제 시각이 되면 화면 데이터를 다시 읽어서 상태가 사라집니다.
